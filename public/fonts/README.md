# Bundled interface fonts

Archivo and IBM Plex Mono match the selected mobile design. Files are distributed unmodified under their accompanying SIL Open Font License 1.1 texts.

Source: https://github.com/google/fonts/tree/1ac2012c34919f5fa2675aacf723fa98edb30b5f/ofl

- `archivo-variable.ttf`: `archivo/Archivo[wdth,wght].ttf`
- `archivo-OFL.txt`: `archivo/OFL.txt`
- `ibm-plex-mono-regular.ttf`: `ibmplexmono/IBMPlexMono-Regular.ttf`
- `ibm-plex-mono-semibold.ttf`: `ibmplexmono/IBMPlexMono-SemiBold.ttf`
- `ibm-plex-mono-OFL.txt`: `ibmplexmono/OFL.txt`

The pinned repository revision is `1ac2012c34919f5fa2675aacf723fa98edb30b5f`. Fonts load from the app deployment base and are precached for offline use.
