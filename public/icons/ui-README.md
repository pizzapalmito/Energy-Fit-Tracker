# Interface icons

The `ui-*.svg` interface icons are unmodified Heroicons outline assets from Tailwind Labs, distributed under the MIT license in `ui-LICENSE.txt`.

Pinned source: https://github.com/tailwindlabs/heroicons/tree/616b7a4dbbf3d011760af8066262cd5c6b3868f3/optimized/24/outline

- Today: `calendar-days.svg`
- Workout: `bolt.svg`
- Exercises: `squares-2x2.svg`
- Progress: `chart-bar.svg`
- Settings: `adjustments-horizontal.svg`

The supplied sketch uses identical placeholder navigation squares. Distinct standard icons improve recognition while retaining its five-tab composition. These do not replace the existing original product/PWA logo assets.
