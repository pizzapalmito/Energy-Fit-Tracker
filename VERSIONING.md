# Versioning

Current version: **0.1.1-beta.2**. The authoritative source is `package.json::version`; the lockfile mirrors it and Settings imports it.

Use monotonic SemVer release identifiers. Beta identifies working offline-first core workflows with regression evidence while real installed-iPhone acceptance remains outstanding. Schema, catalog, backup and algorithm versions remain separate. Update the version and changelog for meaningful user-visible work; never relabel historical artifacts.
